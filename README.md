# U3D FPS Demo

基于 **Unity 2022.3 LTS** 开发的 **第一人称射击（FPS）** 游戏 Demo，个人游戏开发练习作品。

## 🎮 玩法内容
- 第一人称角色控制（移动 / 视角 / 跳跃）
- 射击与子弹系统（弹道 / 命中 / 销毁）
- 武器系统与切换
- 枪械后坐力表现
- 敌人 AI 与受击反馈
- 城市风格场景地图

## 🗺️ 场景（Assets/Scenes）
| 场景 | 说明 |
| --- | --- |
| `SampleScene` | 基础演示场景 |
| `City` | 城市场景 |
| `CityNew` | 城市新场景 |

## 🧩 核心脚本（Assets/Scripts）
- `PlayerControl.cs`：角色控制与开火输入
- `WeaponControl.cs`：武器管理与切换
- `BulletControl.cs`：子弹飞行与命中
- `EmemyControl.cs`：敌人 AI
- `RecoilControl.cs`：枪械后坐力模拟

## 📌 说明
个人 FPS 学习项目，用于展示 Unity 游戏开发能力（角色控制、射击手感、武器系统与场景搭建）。
